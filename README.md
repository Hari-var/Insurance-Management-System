# .NET 10 Starter App

A minimal ASP.NET Core Web API built with .NET 10.

## Run

```powershell
cd StarterApp
dotnet run
```

The app prints its local URL when it starts. Try:

- `GET /` for a welcome response
- `GET /health` for a health status

## Build

```powershell
dotnet build StarterApp/StarterApp.csproj
```
